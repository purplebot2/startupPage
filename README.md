A custom browser start page built with HTML, CSS and JavaScript.

## Features
- Live clock and date
- Weather based on your location
- Google search bar with search history
- Shortcuts (right-click to remove)
- Multiple themes
- Personalized greeting

## Themes
- **Q-ocean** — Dark teal, default theme
- **Sakura** — Japanese night with pink tones
- **Arcade** — Retro pixel game style
- **VDB Theme** — Dark with yellow accent

## Usage
1. Go to [purplebot2.github.io/startupPage](https://purplebot2.github.io/startupPage)
2. Enter your name on first visit
3. Allow location access for weather
4. Add shortcuts with the + button
5. Right-click a shortcut to remove it

## Built with
- HTML / CSS / JavaScript
- [Font Awesome](https://fontawesome.com)
- [Open-Meteo](https://open-meteo.com) — weather API
- [Nominatim](https://nominatim.org) — location API
- [Google Fonts](https://fonts.google.com)
